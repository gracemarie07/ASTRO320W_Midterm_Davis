# ASTRO 320W Midterm Observing Report - Grace Davis

This repository contains my analysis code, measurement exports, Excel workbook, and report for Exercises A–E. Observations were collected with the Artemis group; I performed the analysis and wrote the report.

| Folder | Contents |
| --- | --- |
| notebooks/ | Python notebooks for Exercises A–E |
| scripts/ | Supporting calculations and figure-generation code |
| data/ | AstroImageJ measurement exports and supporting data |
| spreadsheets/ | Excel workbook used for the paired-flat gain measurements |
| results/ | Saved analysis results and plots |
| report/ | Final report (main.pdf), LaTeX source (main.tex), and required figures |

The two A320_bf_stdev algorithms were supplied by the instructor. Raw observing images are stored separately. Assistance with code and report preparation is disclosed in the report appendix.
