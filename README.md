# ASTRO 320W Midterm Observing Report - Grace Davis

Start with `report/main.pdf`. Editable LaTeX is in `report/main.tex`.

| Folder | Contents |
| --- | --- |
| `data/` | `ASTRO320W_Calculations.xlsx`, original AstroImageJ exports, original gain workbook, and supporting measurements |
| `notebooks/` | Image processing, instructor-supplied bias routines, and the Exercise A and C plotting helpers |
| `results/` | Saved analysis outputs and figures |
| `report/` | Paper, LaTeX source, and required figures |

The calculation workbook uses visible Excel formulas for Exercises A-E. Original measurement files are retained. Report figures are saved from the analysis; editable workbook charts show the main numerical trends. Raw observing images are stored separately.

Observations were collected with the Artemis group. I performed the original analysis. Subsequent assistance with code, calculations, Excel, plots, and writing is described in the report appendix.

Open notebooks from `notebooks/`. Image-dependent files use `ASTRO320W_DATA` for the original observing collection, `ASTRO320W_BIAS` for the twenty bias frames, `ASTRO320W_ORGANIZED` for organized images, and `ASTRO320W_E_IMAGES` for named binary fields. Defaults point to `raw/` or `organized_data/` within this folder. Existing saved results do not require the raw images.
